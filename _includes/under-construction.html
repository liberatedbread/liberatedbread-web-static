Usage: {% include under-construction.html %} {% include under-construction.html label="This page is under construction" %} Optional includes: include.label — badge text (default: "Under construction") include.class — extra classes on the wrapper (spacing at the call site; the badge itself never sets its own margins) WHY IT IS DRAWN, NOT AN ANIMATED GIF ------------------------------------ The obvious way to do this is the actual period artifact: a 20-frame construction.gif off a GeoCities mirror. We can't ship one — those files all have owners and none of them is us, which is the same rule the device pages follow for manufacturer photos. So the joke is reconstructed rather than copied: an inline SVG in the bread palette, animated in CSS. Being drawn also buys three things a GIF could not: * it is 1.5 KB of markup and no HTTP request, on every page of the site; * it inherits `currentColor` and the --bread-* tokens, so it tracked the 2026 palette change with no re-export; and * the motion is CSS, so `prefers-reduced-motion: reduce` can freeze it — see the .lb-uc rules in src/input.css. An animated GIF ignores that media query entirely and there is no way to ask it not to. The animation is deliberately stepped, not eased (`steps(1, end)`): a 90s GIF had a handful of discrete frames and snapped between them, and a smoothly interpolated swing reads as a modern loading spinner instead of a throwback. NO IDs, ANYWHERE. This include renders twice on an unverified device guide — once in the verification block, once in the footer — and duplicate ids are invalid HTML and break the very `url(#…)` references that would have needed them.

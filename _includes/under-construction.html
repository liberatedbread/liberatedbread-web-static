{%- comment -%} The 1996 "under construction" badge. The actual artifact, not a redraw. Usage: {% include under-construction.html %} {% include under-construction.html label="This site is under construction" %} Optional includes: include.label — the accessible name, i.e. the alt text. The words UNDER CONSTRUCTION are drawn INSIDE the image, so this is what a screen reader gets instead of the picture, not a caption printed next to it. Default: "Under construction". include.class — extra classes on the wrapper, for spacing at the call site. The badge never sets its own margins. WHERE IT CAME FROM, AND WHY THAT TOOK CHECKING ---------------------------------------------- A genuine GeoCities-era construction.gif is an orphan work: everybody's homepage had one, almost nobody knows who drew it, and none of them is licensed for a commercial site to redistribute. That is the same rule the device guides follow for manufacturer photos, so the one we ship is a public-domain badge off Wikimedia Commons — hand-drawn in GIMP and released by its author with no conditions. Full provenance, the exact scaling command, and the checksum of the file as downloaded are in assets/decor/SOURCE.txt. Read that file before adding a second one. The better-looking candidate we rejected was tagged CC BY-SA on Commons and carried "NON-COMMERCIAL USE ONLY" in its own embedded comments — the page and the file disagreed, and the file is the one that counts. REDUCED MOTION -------------- An animated GIF ignores `prefers-reduced-motion` completely: there is no way to ask it not to loop, and CSS cannot reach inside it. The only lever left is to serve a different file, which is what does here — the reader who asked for less motion gets a still frame of the same badge, and everyone else gets the animation. The must come first; the browser takes the first matching child and falls through to the when the query does not apply. The still is frame 0, so it is the same drawing rather than a substitute graphic: the sign, the digger and the lettering are all there, just not cycling. SIZE ---- width/height are on the and match the file exactly (120x90), so the footer reserves the right box before the image arrives. DESIGN §14.2 forbids layout shift, and this loads on every page of the site. It is 2.7 KB, which is smaller than most of the SVG icons in _includes/social-links.html — the 90s were good at some things. {%- endcomment -%} {%- assign uc_label = include.label | default: 'Under construction' -%}
